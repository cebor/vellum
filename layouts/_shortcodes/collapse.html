{{- /* Folds long command output away without hiding it from search or print. `unsafe` is off, so a raw
written in Markdown would be stripped — this shortcode is the only way to get one. {{< collapse summary="Full output" >}}…{{< /collapse >}} Rendered by _partials/disclosure.html, which `details` shares. */ -}} {{- $summary := .Get "summary" | default (.Get 0) }} {{- if not $summary }}{{ errorf "collapse shortcode in %s needs a summary" .Page.Path }}{{ end }} {{- partial "disclosure.html" (dict "summary" $summary "open" (.Get "openByDefault") "body" (.Inner | .Page.RenderString (dict "display" "block"))) -}}
