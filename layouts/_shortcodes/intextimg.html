{{- /* An image set inline in a run of text — a glyph, a badge, a small mark — sized to the line rather than the column. {{< intextimg url="icon.svg" alt="…" height="1.1em" >}} */ -}} {{- $src := .Get "url" | default (.Get "src") }} {{- $url := $src }} {{- $ratio := "" }} {{- with $.Page.Resources.GetMatch $src }} {{- $url = .RelPermalink }} {{- /* The box before the bytes. Height comes from the caller and width from the file, so the line reserves the mark's width instead of collapsing it to nothing and reflowing the sentence when the image lands. aspect-ratio rather than width/height attributes, because height is already set in CSS here and the attribute pair would be overridden by it on one axis and ignored on the other. Two ways in, because Hugo has no .Width for an SVG and an SVG is what this shortcode is for — a drawn mark set into a line. A raster is measured; an SVG is read, since its viewBox states the ratio in the file and parsing it is the only way to have the box before the fetch. Either way a mark that states no ratio simply gets none, and the line behaves as it did before. The viewBox parse itself lives in image-set.html, which is where the render hook, figure and cover reach it too. It was written here first and stayed here, so for a while this shortcode measured a vector while the partial next to it declared vectors unmeasurable — and a full-column figure shoved 797px down the sheet on load while a 1em mark in a sentence held its place perfectly. One parse, one answer. image-set.html reads .measure only on its raster branch, so an SVG needs no measure passed and gets no resize ladder. */ -}} {{- if eq .MediaType.SubType "svg" }} {{- with (partial "image-set.html" (dict "resource" .)).aspectRatio }} {{- $ratio = printf "aspect-ratio:%v;" . }} {{- end }} {{- else }} {{- $ratio = printf "aspect-ratio:%d/%d;" .Width .Height }} {{- end }} {{- end }}
