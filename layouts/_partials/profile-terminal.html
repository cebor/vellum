{{- /* The profile as a terminal session — the alternative presentation to the drawn view index, over exactly the same params. This is a deliberate foreign object on the sheet, and it does not pretend otherwise: a window with a shadow, sitting on top, the way a photograph is pasted onto a drawing. That shadow is the one place in this theme where depth is not carried by line weight, and it is the whole reason the window reads as a window. Turning it off would leave a mono-coloured box that claims to be a terminal and looks like a code block. It is a real shell, not a picture of one: commands are typed, history walks with the arrow keys, Tab completes, Ctrl+C and Ctrl+L do what they do, and an unknown word gets zsh's own error. The window controls work — close collapses it to a single line, minimise to the title bar, zoom to the frame's full width — because three painted dots that do nothing are the lie this whole component would otherwise be. Without JavaScript there is no input line at all (an input that cannot run anything is worse than none) and the window instead shows the complete session already run: every command, every output, in order. The script does not fetch or rebuild that content — it hides the transcript and replays the very same nodes on demand, so there is one copy of the text, it is translated by Hugo, and it is in the HTML for a crawler. */ -}} {{- $p := site.Params.profile }} {{- $t := $p.terminal | default dict }} {{- /* A shell account has no space in it and site.Params.author usually does, so the fallback is slugified rather than printed as written. */ -}} {{- $user := $t.user | default (site.Params.author | urlize) | default "you" }} {{- $host := $t.host | default (site.Title | urlize) }} {{- $dir := $t.dir | default "~" }} {{- $prompt := printf "%s@%s %s %%" $user $host $dir }} {{- /* One entry per command that has data.
