{{- /* The revision note: the table a drawing carries to resolve the change flags set on its face. One row per marked passage, in document order, each the target of its own flag. It reads what the `ai` shortcode left in Page.Store, which only holds once .Content has been rendered — so this partial has to be called after it in the template, never in the header. A passage that states no note of its own inherits the post's, and failing that the level's own wording. Every flag gets a row; a flag pointing at nothing would be the reference that does not resolve, which is the one failure a drawing reference cannot have. */ -}} {{- $marks := .Store.Get "aiMarks" }} {{- if $marks }} {{- $ai := partialCached "ai.html" . .RelPermalink }} {{- $n := 0 }}

The triangle belongs on the face of the sheet, where it has to be found among prose; a revision table has an ordinary numbered column, and setting the flag twice would make the key louder than the note it keys. The number is the tie, and the flag links to it. */}}
