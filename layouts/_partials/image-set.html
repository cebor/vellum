An SVG that states a viewBox and no width/height has an intrinsic *ratio* and no intrinsic *size*, so the browser stretches it to the column and takes the height from the ratio — neither of which it knows until the file lands. Two ways to derive, and which one applies is the file's own declaration: - The file states width and height in px or bare numbers. Then it has an intrinsic size, the browser is already drawing it at that size, and the attributes restate what is happening rather than changing it. - It states only a viewBox.
