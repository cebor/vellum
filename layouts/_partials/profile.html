An aspect-ratio alone will not do here. The avatar spans two grid rows, and a replaced element with no intrinsic size stretches to fill them: a viewBox-only SVG came out 120×177 with the drawing squashed into it. A stated pair gives it an intrinsic size and the stretch never starts. */}} {{- $set := partial "image-set.html" (dict "resource" $img "measure" $w) }} {{- $h := $w }} {{- if and $set.width $set.height }} {{- $h = int (math.Round (div (mul (float $w) (float $set.height)) (float $set.width))) }} {{- end }} {{- else }} {{- $x1 := $img.Resize (printf "%dx webp q90" $w) }} {{- $x2 := $img.Resize (printf "%dx webp q90" (mul $w 2)) }} {{- /* Both dimensions come off the resized variant, never $w twice. The resize is width-constrained, so only $x1 knows the height that came out of it — and writing $w into both declares every portrait square, which crops nothing but reserves the wrong box and shifts the block as it loads. header.html carries the same note over the same mistake; this is the second place it was made. */}} {{- end }} {{- end }} {{- end }}
