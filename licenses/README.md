# Third-party licences

The theme itself is MIT — see [`LICENSE`](../LICENSE) at the root. It also ships a handful of
third-party assets, and the licences of two of them require their text to travel with the
files. That is what this directory is for; the texts below are verbatim upstream copies and
must not be edited.

| Asset | Files | Licence | Text |
|---|---|---|---|
| **Archivo** | `assets/fonts/archivo*.woff2` | SIL OFL-1.1 — © 2020 The Archivo Project Authors | [`Archivo-OFL.txt`](Archivo-OFL.txt) |
| **JetBrains Mono** | `assets/fonts/jetbrains-mono*.woff2` | SIL OFL-1.1 — © 2020 The JetBrains Mono Project Authors | [`JetBrainsMono-OFL.txt`](JetBrainsMono-OFL.txt) |
| **Fuse.js v7.0.0** | `assets/js/fuse.basic.min.js` | Apache-2.0 — © 2023 Kiro Risk | [`FuseJS-Apache-2.0.txt`](FuseJS-Apache-2.0.txt) |
| **Simple Icons** | icon paths inlined in `layouts/_partials/icon.html` | CC0-1.0 | public domain, no text required |

The font files are subsets of the upstream releases, which the OFL permits; they carry no
Reserved Font Name, so the subsets keep the original names.
