Die README ist die Referenz. Sie führt jeden Param, jeden Front-Matter-Schlüssel und jeden Shortcode
auf, sie liegt im Hugo-Modul und funktioniert offline — und genau deshalb ist sie ein schlechter Ort,
um etwas zu *zeigen*. Diese Seiten übernehmen die andere Hälfte: Sie führen die Funktion auf der
Seite vor, die man gerade liest, und sie wiederholen keine Tabelle, die der README gehört.
