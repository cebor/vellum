The README is the reference. It lists every param, every front-matter key and every shortcode, it
ships inside the Hugo module, and it works offline — which is exactly why it is a poor place to
*show* anything. These pages do the other half: they run the feature on the page you are reading,
and they never repeat a table the README already owns.
